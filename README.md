# 🎓 College Coursework & Labs
### Специальность: 09.02.07 «Информационные системы и программирование» (2 курс, СПО)

Репозиторий для хранения и фиксации практических и лабораторных работ по профильным дисциплинам колледжа.

---

## 📁 Структура работ:

### 1. Веб-технологии (Базовый HTML)
- **Тема:** Создание многостраничного гипертекстового сайта «Времена года» (`index.htm`, `spring.htm`, `summer.htm`, `autumn.htm`, `winter.htm`).
- **Стек:** HTML4/5, табличная вёрстка, навигационные панели, работа с изображениями и форматированием текста.

### 2. Базы данных (MS Access)
- **Тема:** Проектирование реляционных баз данных и связей между таблицами.
- **Практика:** 
  - Создание схемы данных и связей «один-ко-многим» (1:M).
  - Обеспечение целостности данных.
  - Каскадное обновление и удаление связанных записей.
